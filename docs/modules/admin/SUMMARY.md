### 💡 Как использовать

#### Вариант 1: Быстрый старт (5 минут)
```bash
# 1. Скопировать модули в проект
cp -r admin_modules /path/to/your-project/src/

# 2. Создать .env.local
echo "NEXT_PUBLIC_API_URL=https://your-api.com" > .env.local

# 3. Обновить конфигурацию (см. QUICK_START.md)

# 4. Запустить
npm run dev
```
