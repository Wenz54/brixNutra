- Белые карточки с тенью
- Зеленые кнопки (primary actions)
- Серые кнопки (secondary actions)

- Hover эффекты

**Иконки** (@heroicons/react):
- PlusIcon - создание
- PencilIcon - редактирование
- TrashIcon - удаление
- ArrowLeftIcon - назад
- AcademicCapIcon - курсы
- PlayIcon - видео
- DocumentTextIcon - текст
- MusicalNoteIcon - аудио

**Цвета**:
- Бесплатно: blue-100/blue-800
- Платно: green-100/green-800
- Черновик: yellow-100/yellow-800

**Валидация**:
```typescript

register('isPaid') // checkbox

```

