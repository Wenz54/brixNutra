## 📝 Заметки

### Преимущества Mock режима:
- ✨ Независимая разработка UI
- ✨ Быстрое прототипирование
- ✨ Демонстрация функционала
- ✨ Тестирование UX

### Легкое переключение:
```dart
// В каждом сервисе:
static const bool useMockMode = false; // Переключить на false
```

### Интеграция с backend:
1. Переключить `useMockMode = false`
2. Настроить `BASE_URL`
3. Все endpoints уже готовы
4. Обработка ошибок настроена
