# Supply Diets - Dev Modules

Модульная архитектура приложения Supply Diets для удобной разработки и переиспользования компонентов.

## 📦 Список модулей

### Базовые модули
- **core_module** - Базовые сервисы (API, токены, утилиты)
- **ui_kit_module** - Переиспользуемые UI компоненты

### Feature модули
- **auth_module** - Авторизация и регистрация
- **tab_bar_module** - Нижний таб-бар навигации
- **diary_module** - Дневник питания
- **profile_module** - Профиль пользователя
- **plans_module** - Планы питания
- **home_module** - Главный экран
- **knowledge_module** - Курсы и база знаний
- **ai_chat_module** - AI чат
- **checkup_module** - Лабораторные анализы
- **onboarding_module** - Опросник при первом входе
- **subscription_module** - Подписки
- **survey_module** - Опросы

## 🚀 Использование

Каждый модуль можно использовать независимо, просто скопировав его папку в свой проект.

### Быстрый старт

1. Скопируйте нужные модули в свой проект
2. Начните с `core_module` - он содержит базовые сервисы
3. Добавьте `ui_kit_module` для UI компонентов
4. Подключите нужные feature модули

### API Configuration

Все модули по умолчанию настроены на **localhost:3001**

Для изменения базового URL отредактируйте `core_module/config/api_config.dart`

## 🎨 Кастомизация

- **Дизайн**: Каждый модуль имеет свою папку `widgets/` с UI компонентами
- **Цвета**: Настраиваются в `core_module/theme/app_theme.dart`
- **Локализация**: Поддержка русского и английского языков
